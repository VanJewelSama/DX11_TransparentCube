## 1. VS 会自动生成哪些文件

用「空项目」模板创建后，VS 自动生成：

| 文件 | 作用 |
|---|---|
| `TransparentCube_Proj.sln` | 解决方案 |
| `TransparentCube.vcxproj` | 工程文件（所有下面 GUI 里的配置最终都写进它） |
| `TransparentCube.vcxproj.filters` | 解决方案资源管理器里的筛选器（逻辑目录） |
| `TransparentCube.vcxproj.user` | 每用户的调试设置（工作目录等），首次改调试页时生成 |

`.slnx`（VS2026 新格式）如出现也正常，与 .sln 等价。编译产生的 `x64\Debug\` 等中间目录不入库。

## 2. 创建项目（GUI 步骤）

1. **创建新项目** → 选 **「空项目」(Empty Project, C++/Windows)**
2. 项目名：`TransparentCube`；位置：`E:\DX11_projects\TransparentCube_Proj`
3. ✅ 勾选 **「将解决方案和项目放在同一目录中」**（.sln 和 .vcxproj 都在仓库根目录，路径最短）

## 3. 配置管理器

- 打开 **生成 → 配置管理器**
- 删除 **x86/Win32** 平台，只保留 **x64**（Debug、Release 两个配置）

## 4. 项目属性页（右键项目 → 属性）

> 每改一项前，顶部先选 **配置：所有配置 / 平台：x64**，避免重复劳动。

| 属性页 | 项 | 值 |
|---|---|---|
| 常规 | 平台工具集 | **v145** |
| 常规 | Windows SDK 版本 | **10.0.22621.0**（或"最新安装的版本"，两者都行） |
| 常规 | C++ 语言标准 | **ISO C++17** 或 C++20 |
| 高级 | 字符集 | 使用 Unicode 字符集 |
| 链接器 → 系统 | 子系统 | **控制台**（学习期 printf/日志直接可见；用 `main()` 而非 `WinMain()`） |
| 链接器 → 输入 | 附加依赖项 | `d3d11.lib;dxgi.lib;d3dcompiler.lib;windowscodecs.lib;dxguid.lib` |
| 调试 | 工作目录 | **$(ProjectDir)**（让 exe 用相对路径找到 shaders/ 和 assets/） |

附加依赖项说明：
- `d3d11.lib` / `dxgi.lib`：DX11 设备与交换链
- `d3dcompiler.lib`：运行时编译 HLSL（`D3DCompileFromFile`）
- `windowscodecs.lib`：WIC 解码 PNG/JPG 贴图
- `dxguid.lib`：DXGI 调试接口等用到的 GUID 定义

## 5. 目录与筛选器（对应对 01 文档第 3、7 节的 UE-lite 分层）

在磁盘上建好目录，解决方案资源管理器里建同名**筛选器**：

```
src/
├─ main.cpp            ≈ FEngineLoop：Init / Tick / Shutdown
├─ Core/               Window、Timer、Input
├─ RHI/                D3D11Device、D3D11Resources、D3D11States（对 D3D11 的薄封装）
├─ Renderer/           Renderer（分 Pass 绘制）、Shader、Material
├─ Scene/              Scene、SceneObject、Camera、Mesh
shaders/               Common.hlsl、CubeVS.hlsl、CubePS.hlsl
assets/                TextureA.png（可选，缺省时程序生成棋盘格）
```

**shader 文件加入项目后**：右键每个 .hlsl → 属性 → 项类型 = **「不参与生成」**
（本 demo 用运行时编译方案，改 shader 不用重编译工程）

## 6. 两个可选项（后续按需再装）

- **系统「可选功能 → 图形工具」**：开启后创建 Device 才能带 `D3D11_CREATE_DEVICE_DEBUG` 标志（DX11 调试层，报错过早很有用）；代码里做成"拿不到就优雅降级"即可
- **PIX on Windows**：帧抓取分析工具，复习渲染流水线时抓一帧看每个 Pass 非常直观；VS2026 已不再内置图形诊断器
